# Associação de Transporte Universitário

Projeto desenvolvido em Java para gerenciar as operações de uma associação de transporte universitário, utilizando os conceitos de Programação Orientada a Objetos (POO).

## Sobre o projeto

O sistema tem como objetivo auxiliar no gerenciamento do transporte de estudantes universitários, permitindo organizar alunos, motoristas, veículos, rotas, viagens e pagamentos.

## Funcionalidades

- **Gerenciamento de alunos:** cadastro e organização dos estudantes.
- **Gerenciamento de motoristas:** registro e controle dos motoristas.
- **Gerenciamento de veículos:** organização da frota e controle da disponibilidade.
- **Gerenciamento de rotas:** definição de destinos e cálculo de custos.
- **Gerenciamento de viagens:** organização das viagens, turnos, veículos e alunos.
- **Controle de pagamentos:** registro de pagamentos e identificação de atrasos.
- **Controle financeiro:** cálculo de receitas, custos e lucro da associação.
- **Alocação de alunos:** distribuição de estudantes nos veículos conforme a capacidade disponível.

## Tecnologias utilizadas

- Java
- Programação Orientada a Objetos (POO)
- IntelliJ IDEA
- Git e GitHub

## Conceitos de POO aplicados

O projeto utiliza classes, objetos, encapsulamento, construtores, enums e relacionamentos entre classes para representar as entidades e regras de negócio da associação.

## Organização do projeto

- `domain/` — classes que representam as entidades do sistema.
- `Parameters/` — enums e parâmetros utilizados pelo sistema.
- `Services/` — classes responsáveis pelas regras e operações de serviço.
- `TestLab2/` — área destinada aos testes e à execução do projeto.

## Como executar

1. Clone este repositório.
2. Abra o projeto no IntelliJ IDEA.
3. Configure um JDK compatível com o código.
4. Localize a classe que contém o método `main`.
5. Execute essa classe pela IDE.

## Objetivo acadêmico

Projeto desenvolvido para praticar Java e os fundamentos da Programação Orientada a Objetos, aplicados a um problema de gerenciamento de transporte universitário.
